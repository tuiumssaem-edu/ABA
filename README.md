# ABA 행동 관찰 기록기

특수교육 현장과 응용행동분석(ABA) 관찰을 위한 단일 파일 웹 앱입니다. 태블릿·스마트폰에서 행동이 나타나는 순간 한 번의 터치로 강도(약·중·강)를 기록합니다.

## 주요 기능

- 학생 선택 → 해당 학생의 표적행동만 표시되는 연동 드롭다운
- 약(1점)·중(2점)·강(3점) 대형 기록 버튼, 효과음·진동·알림으로 즉시 피드백
- 설정에서 학생 추가·삭제, 학생별 표적행동 배지 추가·삭제
- 구글 스프레드시트 자동 전송 (Google Apps Script, 학생별 시트 자동 생성)
- 시간대별(00~23시) 발생 빈도 막대그래프, 강도 비율 도넛 차트
- 관찰 로그 검색·개별 삭제, 엑셀 호환 CSV(UTF-8 BOM) 내려받기

## 사용 방법

`index.html` 하나로 동작합니다. 저장소의 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 지정하면 아래 주소로 접속할 수 있습니다.

```
https://tuiumssaem-edu.github.io/aba/
```

구글 시트 연동 방법과 Apps Script 코드는 앱 상단의 **시트 연동** 버튼에서 확인할 수 있습니다.

## 데이터 저장 안내

- 관찰 기록은 사용하는 기기의 브라우저(localStorage)에 저장되며 이 저장소나 GitHub 서버로 전송되지 않습니다.
- 브라우저 데이터를 지우면 기록도 함께 사라지므로 정기적으로 CSV를 내려받아 보관해 주세요.
- 구글 시트 웹 앱 URL은 학생 기록이 들어가는 주소이므로 저장소나 공개된 곳에 올리지 마세요.
