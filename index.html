Apps Script 웹 앱 URL을 저장하면 기록할 때마다 시트로 자동 전송됩니다. 설정 방법은 를 참고하세요.

기록 초기화

이 기기에 저장된 관찰 기록을 모두 지웁니다. 구글 시트의 데이터는 지워지지 않습니다.

구글 시트 연동 가이드

  1. 1구글 스프레드시트를 새로 만들고 메뉴에서 확장 프로그램 → Apps Script를 엽니다.
  2. 2편집기의 기존 코드를 모두 지우고 아래 코드를 붙여넣은 뒤 저장합니다.
  3. 3(권장) 함수 목록에서 testSetup을 한 번 실행해 권한을 승인합니다. ‘테스트 학생’ 시트가 생기면 정상입니다.
  4. 4배포 → 새 배포에서 유형을 웹 앱으로 고르고, 실행 사용자는 나, 액세스 권한은 모든 사용자로 지정한 뒤 배포합니다.
  5. 5/exec로 끝나는 웹 앱 URL을 복사해 설정의 ‘구글 스프레드시트 연동’ 칸에 붙여넣고 저장합니다.
코드를 수정했다면 배포 → 배포 관리 → 수정(연필) → 버전: 새 버전으로 다시 배포해야 반영됩니다. 웹 앱 URL을 아는 사람은 누구나 시트에 기록을 추가할 수 있으므로 URL을 공개된 곳에 올리지 마세요.
